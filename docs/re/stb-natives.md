# Inventaire des natives STB employées

## Périmètre et lecture

Inventaire statique des **228 identifiants employés** dans le code atteint des 689 scripts
(80 237 appels), parmi les 304 entrées de la table `ov_001::02164d6c`.
Il consolide dix relevés de handlers, leurs fonctions moteur et les contextes STB.
Il ne redistribue ni scripts, ni textes, ni ressources du jeu et ne constitue pas une
validation sous émulateur. L’[ABI et le format STB](stb.md#natives) restent la référence.

Les adresses de handlers `0215…`/`0216…` sont dans **ov_001**, les helpers
`020…` dans ARM9 ; un autre overlay est précisé explicitement. Ce sont des adresses
virtuelles de la ROM analysée, pas des offsets de fichiers. Les offsets `ev…:0x…`
sont relatifs au code du script. Les noms anglais sont descriptifs, non des symboles
originaux retrouvés. **— : conserver l’ID numérique**. Une écriture de champ établie
ne suffit pas à identifier sa fonction métier. `[INFERENCE]` reste une hypothèse.

Arguments hors numéro natif ; `&` = sortie par adresse ; `[]` = facultatif seulement
lorsque le handler le vérifie. Une arité scriptée trop courte n’établit aucun défaut.
Le retour C du handler est ignoré ; aucun état retourné n’implique une suspension.

Dans les tableaux, `a`/`actor` désigne le contrôleur STB, `b`/`slot` une liaison
sauf mention contraire, `id`/`character_id` un personnage. `F=ov_017::0218b5b0()`,
`E=*(F+0x3734)`, `G=0200f398()`, `R=02012ff4()`. Un champ sans préfixe
explicite appartient à l’objet décrit dans sa ligne.

Les preuves sont les décompilations des handlers de la table et leurs relais moteur,
confrontées aux désassemblages STB ; [les symboles versionnés](../../re/symbols.txt)
fixent les adresses déjà nommées. Les résultats locaux générés ne sont pas requis
pour lire cet inventaire ; aucune capture dynamique nouvelle n’est revendiquée.

Pour 566, la signature dépend du mode : 0/1/9/10/11/12/13 `(mode,n)` ;
2/7 `(mode,chemin,n[,option])`, 6 idem avec ressource `.mon` ;
3 `(3,chemin,n[,option])` sous `data/ani/` ; 4/5 `(mode,référence,n)` ;
8 `(8,n[,option])` avec ressource fixe. La consommation complète de ces
déclarations reste inconnue ; pas de rôle métier général attribué.

### Distinctions à préserver

- **Personnage/modèle** : table `Chara_Get` (`0200fd80`), indices 0–0xe8 ; conversion
  `0215ad2c(id)` : positifs inchangés, négatifs `0x9f-id` (`-1→0xa0`).
  **Liaison** : 32 entrées `{type,id,état,pointeur}`, stride 0x10, configurées par 202.
  **Acteur STB** : 24 contrôleurs 0–23, stride 0x588, accessibles par `0215ab20` ;
  205 sélectionne leur liaison. `ev21500:fn@0xeb0` enchaîne 202, 203, 205.
- Les commandes acteur sont réparties sur **huit files** (`0215a134`) ; même une
  affectation directe attend le traitement de sa file. 207/209/211 temporisée
  comparent à `2×durée`, avec pas moteur lu par `02010230` en `save+0x3c4`.
  `ev03030:0x1e1c/0x1eb8` utilise durées 30/10 puis attentes correspondantes.
  **Ni Hz, ni conversion en secondes, ni unité physique des positions établis.**
  218 et 227 comptent autrement ; 840 expose ce pas, 838 un compteur distinct.
- **210 ≠ 224** : 224 attend la fin de l’animation courante, 210 ne l’attend pas.
  Flags 210 : `0x01` arrête sans rebouclage, `0x04` inverse la progression,
  `0x08` force le redémarrage, `0x10` prépare la transition ; preuves moteur
  `02036e44`, `02034ea0`, `020352f8`. Bit 2 et effet du quatrième flottant inconnus.
- Caméra : œil `E`, cible `T`, azimut `θ` en radians, **hauteur relative `h` (pas pitch)**,
  distance totale `r` (pas rayon horizontal). `0202e5e8` reconstruit
  `E=T+Ry(θ)·(0,h,sqrt(r²-h²))`. Les commandes sont en file ; le prédicat 301
  n’examine que quatre files alors que la mise à jour en traite cinq.
- Fondus : **C0/C1 ne signifient pas haut/bas ni main/sub démontrés** ; verrous
  contrôleur +0x24/+0x25. Durée et cadence non établies ; les handlers ne bloquent pas.
- Messages : `W=020421b0()`. 405 expose l’octet `W+0x19bd` (1 : attente en cours,
  0 : réinitialisé ; enum complet inconnu), **558 lit la réponse `W+0x954`**.
  Pour le chemin **YESNO documenté seulement : 0=oui, 1=non** ; preuve :
  `ev01160:0x20f8` lit 558 après le message 210, `0x211c` teste zéro,
  et [condition trigger 0x10](trigger.md), [codes YESNO/NOYES](text.md).
  Pas de généralisation à NOYES, aux variantes, ni à l’annulation.
- **726–728 sont sonores**, pas flags/quêtes : groupe + archive SE, restauration
  de heap, puis index local. `ev03030:0x16b4` sélectionne 231 ; `0x2b84`
  sélectionne 237 et `0x2bc0` joue l’index 1. Ne pas confondre avec un ID BGM.
