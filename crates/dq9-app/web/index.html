DQ9 Rust — démo technique : aide et limites

Sélectionnez votre propre ROM européenne de Dragon Quest IX (YDQP01), puis cliquez sur « Nouvelle partie ». Une sauvegarde DS peut aussi être chargée. Ces fichiers restent dans votre navigateur : ils ne sont jamais envoyés au serveur.

Cliquez dans le jeu pour utiliser le clavier : flèches pour marcher, Entrée ou Espace pour parler et avancer les messages, Q/E pour tourner la caméra. M coupe le son ; le navigateur ne l'autorise qu'après une interaction.

Version expérimentale : combats sautés, effets encore incomplets et écran inférieur provisoire. Navigateur récent avec WebGPU ou WebGL 2 requis ; ordinateur et clavier recommandés. Aucune ROM n'est fournie.
